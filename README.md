# FIFA Player Position Analysis

A data-analysis project exploring FIFA player data with Python, with a focus on player positions and the attributes associated with different roles on the pitch.

## Overview

This repository contains a Jupyter Notebook used to explore and analyse FIFA player data, together with the final project presentation.

The project demonstrates an end-to-end analytical workflow: working with a sports dataset, preparing the data, investigating player characteristics and communicating the findings through a presentation.

## Repository Contents

| File | Purpose |
| --- | --- |
| `project1_fifa_position_def.ipynb` | Main Python/Jupyter analysis |
| `FIFA PROJECT PRESENTATION 2023.pdf` | Final presentation of the project and findings |

## Analysis Focus

The notebook focuses on FIFA player positions and uses player-level information to investigate how characteristics differ across roles. The analysis provides a practical example of turning a raw dataset into an interpretable sports-data study.
